# Tiny Ghost Hotel — v0.2 Design Direction

## Theme
A cosy, creepy, old-world haunted hotel. Think late-Victorian reception desk, candlelight, brass keys, worn velvet, dark wood, moonlight, old paper, hand-painted signage and friendly ghosts.

The game should feel mysterious rather than horror-heavy: spooky enough to be memorable, warm enough to be inviting.

## Core progression
1. Start a night.
2. Read each ghost's clues.
3. Assign the guest to the most suitable room.
4. Earn coins, streak bonuses and hotel reputation.
5. Complete the shift.
6. Spend earnings on rooms and facilities.
7. Unlock new rooms, guests and hotel wings.
8. Repeat with more demanding guests and events.

## Planned screen flow
Main Menu → Load / New Game → Night Introduction → Reception → Room Assignment → Guest Feedback → End-of-Night Summary → Hotel Upgrades → Ghost Book / Hotel Map → Next Night.

## Visual rules
- Gothic serif display typography paired with simple readable body text.
- Brass/gold borders on charcoal, wine red, midnight blue and aged parchment.
- Warm candlelight against cool moonlight.
- Animated fog, dust, candles, chandeliers and subtle portrait movement.
- UI panels should look physically part of the hotel: ledgers, plaques, room keys, framed notices and old menus.
- Ghosts remain expressive and charming, never gruesome.
